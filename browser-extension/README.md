# Avito Chat Analyzer — Chrome extension (prototype)

Версия: 0.1.0  
Статус: локальный прототип, не готов к промышленному использованию.

## Что уже делает

- Работает только на активной вкладке `https://www.avito.ru/*`.
- Требует явного действия пользователя: открыть popup и нажать «Сформировать JSON».
- Экспортирует только текст, который пользователь сам выделил мышью на странице.
- Добавляет внутреннюю подпись аккаунта и необязательный период.
- Сохраняет JSON локально через стандартный диалог загрузки Chrome.

## Чего пока не делает

- Не обходит чаты и не собирает историю автоматически.
- Не определяет границы сообщений, автора и временные метки.
- Не загружает данные на сервер.
- Не синхронизируется в фоне и не работает при выключенном компьютере.
- Не использует cookies, пароли, токены, внутренние API или сетевые запросы к Avito.
- Не отправляет, не удаляет и не помечает сообщения прочитанными.

Это намеренно ограниченный первый прототип: DOM-структура интерфейса Avito ещё не исследована и не проверена на реальном тестовом чате. Автоматический сбор всей истории нельзя включать до проверки селекторов, точности атрибуции сообщений и соответствия действующим правилам Avito.

## Установка для локального теста

1. Скачай репозиторий или открой папку `browser-extension` на компьютере.
2. В Chrome открой `chrome://extensions`.
3. Включи «Режим разработчика».
4. Нажми «Загрузить распакованное расширение».
5. Выбери папку `browser-extension`.
6. Открой Avito, зайди в нужный чат, выдели видимый текст сообщений.
7. Нажми значок расширения, введи подпись аккаунта и период, затем сформируй JSON.

## Формат JSON

Верхний уровень содержит `schema`, `schema_version`, `exported_at`, `source`, `account`, `period`, `conversations` и `limitations`. Сырые данные лежат в `conversations[].raw_text`; массив `messages` пока пустой, поскольку авторство и временные метки не выводятся автоматически.

Следующий этап — получить тестовый JSON с реального чата (личные данные можно заменить), согласовать нормализованную схему и только затем реализовать надёжное распознавание отдельных сообщений и импорт в серверный анализатор.
