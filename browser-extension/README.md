# Avito Chat Analyzer — Chrome extension

Версия: 0.2.0  
Статус: диагностическая сборка, не является автоматическим сборщиком чатов.

## Новое в 0.2.0

Добавлена кнопка «Проверить структуру экрана». Запусти её дважды:
1. На странице со списком диалогов.
2. Внутри открытого диалога.

Расширение сохраняет локальный JSON со структурой видимых элементов: HTML-теги, CSS-классы, повторяемость элементов, наличие ARIA/data-атрибутов, размеры и количество дочерних элементов. Значения имён, текст сообщений, aria-label, ссылки, значения полей, cookies и сетевые данные не собираются. Ничего не отправляется на сервер.

## Старый режим

Кнопка «Сформировать JSON» по-прежнему экспортирует только текст, который пользователь явно выделил мышью. Это не сбор истории.

## Как установить или обновить

1. Скачай актуальную папку `browser-extension` из ветки `feature/chat-analyzer-mvp`.
2. Открой `chrome://extensions`.
3. Если установлена предыдущая версия, нажми «Обновить» на карточке расширения или удали старую распакованную папку из списка и загрузи новую.
4. Включи «Режим разработчика» и нажми «Загрузить распакованное расширение».
5. Выбери обновлённую папку `browser-extension`.

## Как провести диагностику

1. Открой список сообщений Avito и нажми «Проверить структуру экрана».
2. Сохрани файл с названием `avito-dom-diagnostic-...`.
3. Открой любой диалог и повтори действие.
4. Пришли оба JSON-файла сюда.

Диагностика снимает только видимую структуру DOM. Она нужна, чтобы определить повторяемые элементы списка чатов и сообщения, прежде чем разрабатывать автоматическую навигацию.

## Ограничения

- Автоматический обход чатов, извлечение сообщений и серверная загрузка ещё не реализованы.
- DOM-диагностика не гарантирует, что весь список/история загружены в браузере.
- Автоматический сбор можно разрабатывать только после проверки интерфейса, точности авторства/времени и соответствия правилам Avito.
- Расширение не читает cookies, пароли, токены и не вызывает скрытые API.
- Оно не отправляет, не удаляет и не помечает сообщения прочитанными.
